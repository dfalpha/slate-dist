# slate-dist

Public mirror of the files a Slate install fetches. **Generated - do
not edit here.** Every file is overwritten by
`.github/workflows/dist.yml` in the (private) Slate repository on
each server promotion; an edit made here is lost at the next one.

Install a Slate server:

| OS | Command |
|---|---|
| Linux | `curl -fsSL https://get.slatepanel.app/linux \| sudo sh` |
| Windows 11 | `irm https://get.slatepanel.app/windows \| iex` (elevated PowerShell 7) |
| macOS (beta) | `curl -fsSL https://get.slatepanel.app/mac \| sh` |
